# Airplane Tracker

Курсовой проект по интеграции с внешними API для отслеживания самолётов в воздушном пространстве выбранных стран. Реализован на Python с соблюдением принципов чистой архитектуры и ООП.

## Описание проекта

Проект решает задачу получения информации о воздушных судах через публичные API (Nominatim + OpenSky Network) и предоставляет пользователю инструменты для фильтрации и сортировки данных.

### Ключевые особенности реализации:
- **Чистая архитектура**: Четкое разделение на слои приложения и инфраструктуры. Бизнес-логика не зависит от конкретных реализаций API или хранилищ.
- **Абстракция**: Использование абстрактных базовых классов (`BaseAPIConnector`, `BaseStorage`) позволяет легко заменять источники данных или типы хранилищ без изменения бизнес-логики.
- **Инкапсуляция и валидация**: Модель `Aeroplane` скрывает детали реализации и гарантирует целостность данных через валидацию при создании.
- **Устойчивость**: Реализация коннектора предусматривает корректную обработку сетевых ошибок и нестандартных ответов API.
- **SOLID**: Соблюдены принципы единственной ответственности (SRP) и открытости/закрытости (OCP).

## Установка и запуск

1. Клонируйте репозиторий:
     git clone <repo-url>
   cd airplane-tracker
2. Установите зависимости:
   poetry install
3. апустите приложение:
   poetry run python main.py

Проверка качества кода
# Форматирование
poetry run black src/ tests/
poetry run isort src/ tests/

# Линтинг
poetry run flake8 src/ tests/ --max-line-length=90

# Тесты с покрытием
poetry run pytest tests/ -v --cov=src --cov-report=term-missing

Технологии

Python 3.10+ — язык программирования
Poetry — управление зависимостями и проектом
requests — HTTP-клиент для работы с API
pytest / pytest-cov — тестирование и измерение покрытия
Black / isort / flake8 — форматирование и линтинг
GitFlow — модель ветвления

Требования к коду
Проект следует стандартам PEP 8 и внутренним соглашениям:
Именование в snake_case
Максимальная длина строки: 90 символов
Обязательные type hints для всех сигнатур
Docstrings для всех публичных классов и методов
Покрытие тестами ключевой логики: ≥75%
